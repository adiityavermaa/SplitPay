# SplitPay — UPI Payment Simulator with Automated Transaction Splitting

**5th Semester B.E. CSE Mini-Project**

> ⚠️ All payments are simulated against a mock database. No real UPI rails,
> banks, or NPCI systems are involved.

## Setup

### Backend
cd server && npm install && node initDb.js && node app.js

### Frontend
cd app && flutter pub get && flutter run
